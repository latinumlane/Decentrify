# Deploy `work.decentrify.biz`

1. In Netlify, create a new site and deploy the contents of this package (the folder containing `index.html` and `netlify.toml`).
2. In **Domain management**, add `work.decentrify.biz` and complete Netlify's DNS instruction for that hostname.
3. Confirm the published site's **Publish directory** is the repository root (`.`). No build command is required.

The site uses Netlify Forms for the client onboarding form. Submissions appear in the site's Forms area after the first production deploy.

The main site links to this portfolio at `https://work.decentrify.biz/`.
