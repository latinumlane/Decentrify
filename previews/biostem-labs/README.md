# BioStem homepage iframe preview

Upload this entire folder unchanged, then embed `index.html`:

```html
<iframe
  src="/static-homepage-preview/index.html"
  title="BioStem Labs homepage preview"
  loading="lazy"
  style="width: 100%; height: 900px; border: 0;"
></iframe>
```

This is a visual, static preview. Navigation remains inside the iframe and backend-only features (checkout, account, email capture, analytics, and the access gate) are disabled.
